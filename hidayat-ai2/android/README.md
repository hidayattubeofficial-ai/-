# Hidayat AI 2 Android APK

This directory is the Android client layer for Hidayat AI 2.

## Contract
- Connect to the existing FM Computer API at http://127.0.0.1:8080 when running on the FM Computer.
- Do not replace or modify the FM Computer API.
- Ollama remains a supporting local model runtime.
- FM Home approval is required for governed actions.
- YouTube automatic publishing is disabled.

## Build
The Android Gradle project will be added here without changing the existing website/backend.
