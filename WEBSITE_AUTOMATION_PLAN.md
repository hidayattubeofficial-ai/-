# Website Automation Plan

## Ownership
- Website operations: Luna/automation workflows
- YouTube channel operations: Luna assistant oversight
- Owner: Hidayat Tube Official
- Public release: human approval required

## Automation stages
1. Detect website/content changes.
2. Validate project files.
3. Run security/health checks.
4. Prepare approved website content.
5. Deploy only through an explicitly approved deployment workflow.
6. Report success/failure and pending approvals.

## Safety rules
- Never expose API keys in frontend files.
- Never enable YouTube publishing automatically.
- Never publish unapproved content publicly.
- Keep reports auditable through GitHub Actions summaries.
