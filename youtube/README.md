# Hidayat Tube Official — YouTube Content Vault

This directory is separate from the public Cloudflare website.

## Categories
- Neki
- Namaz
- Quran
- Hadith

## Per-video permanent record
Each approved video should keep its story/script, verified references, voice/audio, nature background source record, thumbnail, final video, and metadata/manifest under its category.

## Branding
Every generated video uses Hidayat Tube Official branding and a Like/Subscribe CTA.

## Approval lock
YouTube publishing remains OFF. Nothing is published automatically; human approval is required before any upload.

## Storage rule
Text, references, metadata, and manifests are repository artifacts. Large media files must be stored using an appropriate large-file/release storage mechanism rather than silently discarded as temporary Actions artifacts.
