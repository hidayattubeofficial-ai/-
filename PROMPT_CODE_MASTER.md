## Universal safe workflow
READ-ONLY → CURRENT-STATE → BACKUP-FIRST → DEPENDENCY-CHECK → BLAST-RADIUS → ROOT-CAUSE → MINIMAL-CHANGE → DRY-RUN → HUMAN-APPROVAL → IMPLEMENT → TEST → REGRESSION-GUARD → HEALTH-CHECK → VERIFY → CHANGE-REPORT → ROLLBACK

## FM AI workflow
FM-AUDIT → SOURCE-OF-TRUTH-LOCK → CURRENT-STATE → FM-ROOT-CAUSE → MINIMAL-CHANGE → DRY-RUN → FM-APPROVAL → FM-IMPLEMENT → FM-TEST → SECURITY-CHECK → FM-HEALTH → REGRESSION-GUARD → AUDIT-TRAIL → FM-REPORT

## Agent workflow
MISSION → SCOPE → NON-GOALS → INPUTS → SOURCES → TOOLS → PERMISSIONS → CONSTRAINTS → SUCCESS-CONDITION → STOP-CONDITION → PLAN → HUMAN-IN-LOOP → EXECUTE → VERIFY → AUDIT-TRAIL → REPORT

## Automation workflow
TRIGGER → VALIDATE → DRY-RUN → APPROVAL-GATE → EXECUTE → VERIFY → LOG → REPORT → ALERT-IF-FAILED → ROLLBACK-IF-NEEDED

## Content workflow
RESEARCH → VERIFY → OUTLINE → SCRIPT → FACT-CHECK → PRODUCTION → QA → HUMAN-APPROVAL → SCHEDULE → PUBLISH → MONITOR → REPURPOSE
